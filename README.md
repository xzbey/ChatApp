# ChatApp

Клиент-серверное многопользовательское приложение-мессенджер, разработанное на **Qt 6 / C++17** с использованием системы сборки **CMake**. Проект разделен на независимые сетевые модули (серверную и клиентскую части) и использует кастомные сетевые протоколы для обмена сообщениями и авторизации.

---

## 📌 Архитектура и структура проекта

Проект состоит из общей статической библиотеки протоколов, двух бэкенд-серверов с графическим интерфейсом администратора/мониторинга и клиентского приложения.

## ⚙️ Особенности реализации компонентов

1. **Общая библиотека (`common`)**
   * Содержит заголовки с описанием сетевых структур и форматов пакетов (`AuthProtocol.h`, `ChatProtocol.h`, `ValidationProtocol.h`), используемых как клиентом, так и серверами для сериализации/десериализации данных.

2. **Серверы (`auth_server` и `chat_server`)**
   * **Бэкенд:** Реализованы на базе `QTcpServer` / `QTcpSocket` (модуль `QtNetwork`), обеспечивают многопользовательское сетевое взаимодействие.
   * **Интерфейс (UI):** Созданы на классическом фреймворке **Qt Widgets** (`QMainWindow`, `.ui` файлы). Позволяют администраторам мониторить текущие подключения, логировать события сервера в реальном времени и управлять его состоянием.

3. **Клиентское приложение (`client`)**
   * **Интерфейс (UI):** Разработан **полностью на QML (Qt Quick)** с использованием декларативного подхода и кастомных моделей данных (`QAbstractListModel` под капотом для списков сообщений и чатов).
   * **Логика:** Связывает QML-интерфейс с сетевым клиентом через C++ классы-контроллеры (`ApplicationController`, `AuthService`, `ChatService`).
   * **Функционал:** Поддерживает экраны авторизации/регистрации (`Auth.qml`) и интерфейс обмена сообщениями (`Chat.qml`) с поддержкой общего чата и личных сообщений с активными в сети пользователями.

## 🚀 Сборка и запуск проекта

### Требования
* Установленный **Qt 6.10.1** (с поддержкой необходимых модулей Widgets и Quick).
* Установленный **CMake** (версии 3.16 или выше).

### Инструкция по сборке (через Qt Creator / CMake)
1. Откройте корневой каталог или главный файл `CMakeLists.txt` через **Qt Creator**.
2. Выберите комплект сборки, например, *Desktop Qt 6.10.1 MSVC2022 64bit*.
3. Настройте проект и запустите сборку (`Build Project`).

### 📦 Запуск готовых исполняемых файлов (.exe)
Если проект уже был собран, вы можете запустить приложения напрямую из директории сборки (например, `build/Desktop_Qt_6_10_1_MSVC2022_64bit-Release/`) без повторной компиляции в IDE:

* **Сервер авторизации:** `auth_server/auth_server.exe`
* **Сервер чата:** `chat_server/chat_server.exe`
* **Клиент:** `client/appclient.exe`

> **Важно:** Для корректной работы мессенджера компоненты должны запускаться в строго определенном порядке: сначала оба сервера (`auth_server`, затем `chat_server`), и только после этого клиентское приложение (`appclient.exe`).
